# HW05 deliverable map

| Requirement | Minimum evidence |
| --- | --- |
| Load, Stress, Spike | Named k6 plan, dedicated CSV, command, raw output, distinct report view, resource screenshot |
| Human review | AI defect/omission, correction, and reason the AI missed it |
| Account lockout | Isolated accounts, reset/wait procedure, before/after evidence if triggered |
| Hardware | Hardware screenshot with matching hostname and a spec table |
| Endurance | 10–15 minute raw output, Grafana/resource view, maximum stable RPS and memory ceiling |
| AI analysis | AI output plus raw-value corrections for every identified misinterpretation |
| Recommendations | Feasible/conditional/hallucinated classification backed by source inspection |
| Continuous testing | Commit decision flow, p95 regression gate, cost and false-alarm trade-offs |
| Demo | At least six minutes, Vietnamese narration, tool and resource monitor in one frame |
| Audit | AI tool, date/time, exact prompt, output or output artifact for every interaction |
| Submission | Markdown/PDF reports, README summary, issue evidence if any, commit log, skill, links |

## Final integrity checks

- Replace every `TODO`, `TBD`, sample credential, and placeholder link.
- Ensure the three final plan names follow `{StudentID}_{ScenarioType}_{YYYYMMDD}`.
- Ensure the endpoint-group assignment is one-to-one.
- Ensure raw outputs are full and unedited.
- Ensure report metric values can be traced to raw outputs.
- Ensure screenshots and the video show the real hostname and execution environment.
