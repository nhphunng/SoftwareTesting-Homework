# Execution Evidence

Store only real, attributable evidence:

```text
evidence/
├── screenshots/
│   ├── load/
│   ├── stress/
│   ├── spike/
│   └── endurance/
├── hardware/
└── video/
```

For each measured run, capture k6 and the backend resource monitor in the same frame. Hardware evidence must show the real machine/hostname and match previous homework deployments. Record the unlisted YouTube link only after the tester uploads a video with their own Vietnamese narration.
