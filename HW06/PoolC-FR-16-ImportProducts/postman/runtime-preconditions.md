## CSV workflow finding

Step J source inspection confirmed that a real CSV UI workflow does exist in `eshop-sut/frontend-admin/src/App.jsx`: the browser reads a selected file with `FileReader`, parses rows client-side, then sends JSON `{ products: ... }` to `POST /api/admin/import-products`.

However, there is still no HTTP CSV upload/multipart endpoint. Therefore the CSV-specific cases cannot be executed faithfully by the Postman/Newman API collection alone without reimplementing the browser parser, which would test a copy rather than the real frontend workflow.
