# HW06 AI Audit Report

## Declaration

I use AI tools for the following tasks in HW06. Each significant interaction is recorded in `ai-audit/interactions/` and indexed by `ai-audit/audit-log.md`.

## Audit Method

For each significant AI interaction, retain:

- AI tool name;
- date and time;
- homework stage and API scope;
- original prompt;
- AI output sufficient for traceability;
- affected artifacts;
- human decision (`ACCEPT`, `MODIFY`, or `REJECT`);
- reason and corrections when applicable;
- final result.

The detailed interaction records are append-only evidence. This report is a curated summary built from those records and must not replace or rewrite the original history.
